# 面试题库（基于当前项目整理）

本题库从 `interview` 目录已有内容抽取而来，重点覆盖：

- 工程化（Webpack）
- 微前端（qiankun / 手写实现思路）
- 性能优化（缓存、加载策略、传输）
- 算法与数据结构（基础高频）
- 场景题（排障与优化表达）

## 使用建议

- 每题先尝试口述 30~60 秒，再看参考答案。
- 参考答案按“定义 -> 原理 -> 实践 -> 注意点”组织，方便结构化表达。
- 每轮复习优先过 `工程化`、`性能优化`、`微前端` 三个目录。
